# מפה אישית: ראש · לב · בטן — שאלון דיגיטלי אינטראקטיבי

כלי רפלקציה אישי לסדנת ניהול של NGG. המשתמש מדרג 18 היגדים בסולם 1–5, והמערכת מחשבת ציון נפרד לשלושה "מרכזים ניהוליים" — **ראש** (חשיבה אנליטית), **לב** (אינטליגנציה רגשית) ו**בטן** (אינטואיציה ואומץ ניהולי) — ומציגה מפה אישית.

> הכלי אינו שאלון אבחוני מתוקף מחקרית. מטרתו לעורר מחשבה ולשמש עוגן לשיח, ללמידה ולרפלקציה.

## הפעלה

`index.html` הוא קובץ עצמאי ללא תלויות ובלי שלב build. ניתן לפתוח אותו ישירות בדפדפן, או להעלות לכל שרת סטטי. נדרש חיבור רשת רק לטעינת הפונטים מ-Google Fonts; ללא רשת המערכת נופלת חזרה לפונט מערכת.

## עקרונות מימוש מרכזיים

- **החלוקה לקטגוריות מוסתרת מהמשתמש.** במהלך המענה מוצגת רשימה אחת רציפה של 18 היגדים בסדר אקראי, ללא כותרות קטגוריה וללא רמז לחלוקה. השיוך לקטגוריה (`head` / `heart` / `gut`) הוא נתון פנימי בקוד המשמש אך ורק לחישוב.
- **ערבול (shuffling)** ברמת ההיגד הבודד, אקראי בכל טעינה. התשובה נשמרת לפי `id` ההיגד ולא לפי מיקומו בתצוגה.
- **ניקוד:** סכום 6 היגדים לכל מרכז, טווח 6–30. רמות: נמוך (6–14), בינוני (15–22), גבוה (23–30).
- **פלט:** ציון ורמה לכל מרכז, הדגשת המרכז הדומיננטי והמרכז לפיתוח. בשלב זה מוצגים שמות המרכזים.
